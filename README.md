# 🎉 Smart Calculator (스마트 파티 계산기)

단순한 덧셈 뺄셈은 가라! 더치페이부터 랜덤 뽑기, 심지어 복잡한 연립방정식까지 한 번에 해결해 주는 만능 스마트 계산기 웹 앱입니다. Streamlit을 기반으로 제작되어 PC와 모바일 어디서든 깔끔하게 작동합니다.

## ✨ 주요 기능

* **💸 완벽한 N빵 (Dutch Pay):** 복잡한 총액도 설정한 인원수만큼 정확하게 나눠줍니다.
* **🎲 랜덤 뽑기:** 밥값 내기, 순서 정하기에 유용한 랜덤 숫자 추출 기능 (정수/실수 지원).
* **🧮 수학 봇 (방정식 풀이):** `SymPy` 엔진 탑재! 1차/2차 방정식은 물론, 쉼표(,)로 구분하면 연립방정식의 해까지 단숨에 찾아냅니다.
* **📜 영수증 저장:** 계산했던 모든 내역을 기록하고, 원할 경우 `.txt` 파일로 다운로드할 수 있습니다.
* **🎁 시크릿 이스터에그:** 계산기에 특정 숫자를 입력하면 화면에 화려한 이펙트가 쏟아집니다. 직접 찾아보세요!

## 🚀 사용 기술
* Language: `Python 3`
* Web Framework: `Streamlit`
* Math Library: `SymPy`
